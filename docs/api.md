# hetida designer REST API

The hetida designer backend and hetida designer runtime offer a comprehensive REST API.

Besides the endpoints necessary for the frontend it includes routes for execution of transformations by external services, maintenance endpoints, for dashboarding and the builtin scheduling.

Which endpoints are available depends on the role of the running service (backend, runtime, combined).

The API is documented via the [openapi.json](../runtime/openapi.json) file. We recommend to open it with an openapi viewer application.
